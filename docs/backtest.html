Projection error mean absolute error per player-game, model vs each player's trailing-10 average

Bias is projection minus actual, so a positive number means the model runs high. "24+ min" rows are players projected for at least 24 minutes, which is roughly the set that gets a prop line.

Threes calibration of P(at least k made)

Each row groups player-games by what the model said. A calibrated model's "actually hit" matches "model said" in every row. Brier score is the mean squared error of the probability (lower is better); the base-rate Brier is what you'd get by always predicting the season-wide hit rate.

Points, rebounds, assists, PRA calibration at the fair line

The fair line is the x.5 line where the model's P(over) is nearest 50%. The first table steps that line up and down in whole points, the way books post alternates. The second groups all of those alt lines by the model's P(over). No actual market lines are involved.

By absent starters the usage bump and minutes redistribution both key off this

Rows split by how many regular starters the model believed were out for that team. If the per-36 gap widens as absences rise, the usage bump is overshooting; if the minutes bias changes sign, the redistribution share is off.
